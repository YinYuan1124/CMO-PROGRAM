“弗里斯兰旗帜”演习（Frisian Flag）

 

日期/时间： 2012年4月25日 / 11:00:00 祖鲁时间

地点： 西北欧

可玩方： 蓝方

设计者：Tomcat84

 

引言
“弗里斯兰旗帜”是由荷兰皇家空军在吕伐登空军基地（Leeuwarden AFB）主办的年度多国演习。演习主要侧重于战斗机以混合作战空中行动（COMAO）编组协同作战。多年来，来自不同国家的各类参演者参与其中，形成了有趣的机型组合。演习为期两周，每天飞行两个任务，任务种类多样，包括防御性制空、空中遮断、护航、动态目标打击及其组合等。

在本剧本中，你负责演习第二周的一个下午蓝方编组，任务包括空中遮断（AI）和动态目标打击（DT），能否顺利完成任务全看你的指挥。

为让你了解规模，今天计划从吕伐登起飞的飞机如下：

蓝方空中兵力：

  • Byte 编队——英国皇家空军“台风”（Typhoon）x 4——空中遮断任务
  • Shock 编队——德国空军“台风”x 4——攻势制空（OCA）任务
  • Stingray 编队——芬兰空军 F-18 x 4——攻势制空任务
  • Archer/Killer 编队——荷兰 F-16 x 8——空中遮断/压制敌防空（DEAD）任务
  • Norman 编队——挪威 F-16 x 4——空中遮断任务
  • Hunter 编队——瑞典“鹰狮”（Gripen）x 4——动态目标打击任务
  • King 编队——波兰 F-16 x 4——空中遮断任务
  • Grim 编队——美国驻欧空军（USAFE）F-15 x 4——攻势制空任务
  • Magic 编队——北约 E-3 x 1——预警机（AWACS）任务

剧本设计者说明
希望你享受本剧本。以下是一些建议，助你获得最佳体验：
- 我建议你在“游戏选项 -> 消息日志”菜单中关闭“剧本事件”通知。否则你会看到某些事件何时触发，从而对谁在紧急起飞等情况获得不切实际的态势感知（SA）。

- 但一定要打开“特殊消息”，这有助于执行动态目标打击任务。

- 敌方熟练度设为“新手”（novice），以产生略微更真实的导弹命中概率（PH）。当未来的软件更新改变命中概率的计算方式时，这一点可能会变化。蓝方熟练度最初也出于同样原因设为“新手”，但在加入熟练度对 OODA 循环的影响后，已调整为“普通”（Regular）。如果你想增加挑战，可以在剧本编辑器中手动更改熟练度等级。

- 开始前请务必检查你方的条令/电磁管制（EMCON）是否符合你的喜好。例如，我习惯将手动规避设为“否”，本剧本便以该设置开始。可按需自行调整。

- 我建议关闭“弹尽时返航”（RTB when winchester）条令，也不要直接命令单位在交战区域中央返航，而应先引导它们飞完大部分返航航程。否则它们可能会被困在无法进入的德国空域。

当然，一切随你，预期的空域限制（你将在简报中读到）也是如此。我无法强迫你遵守，只是将其作为一点拟真设定呈现。祝你玩得愉快，欢迎在 Matrixgames Command 论坛 告诉我你的想法，你可以在那里以 Tomcat84 的名字找到我。
