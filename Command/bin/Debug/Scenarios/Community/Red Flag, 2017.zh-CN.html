红旗军演 2017

日期/时间： 2017年7月19日 / 04:00:00 祖鲁时间
地点： 美国内华达州 
可玩阵营： 蓝方
设计者： Tomcat84

简介 
“红旗”是举世闻名的演习，每年在内华达州内利斯空军基地（Nellis AFB）举行多次。它是“所有旗帜演习之母”，具备战斗机飞行员在演习中所能期望的一切：专职假想敌战斗机、大量 SAM 发射装置、良好的空域以及大量实弹轰炸目标。它主要侧重于战斗机在 COMAO 编队中协同完成富有挑战性的目标。在为期两周的时间里，每天飞行两个任务（一次昼间、一次夜间），任务种类繁多，如防御性制空、空中遮断、护航、动态目标打击及其组合等。

本场景让你指挥“红旗 17-3”演习第二周的一个夜间蓝方编队，担负 AI 和 DT 任务，能否成功全看你的了。

场景设计者注释
希望你喜欢这个场景。以下一些建议可让你获得最佳体验：
- 你可以加载六个随附的自定义图层，让作战区域尤其是目标区域更生动一些。我建议将文件放入 Command Modern Air Naval Operations\Overlay\Red Flag 2017\ 文件夹，并从那里加载。文件名以数字开头，应按顺序加载。这是因为较详细的目标区域需要叠在较不详细的大区域图层之上。即 1-flot.png、2-vegasoverview.png、3-targetoverview.png、4-nellis.png、5-northtarget.png 和 6-southtarget.png

- 如果使用这些图层，建议禁用 Relief 图层并启用 BMNG（场景应以此状态启动，可随意在“View”菜单中检查）。

- 此外，我建议在“游戏选项 -> 消息日志”菜单中关闭“场景事件”通知。否则，当某些事件触发时你就会看到，从而获得关于谁正在紧急起飞等的不真实态势感知。

- 但是，请务必开启“特殊消息”，因为这有助于处理 DT 任务。

- 请务必检查所有阵营条令设置，使其符合你的喜好（例如，我将自动规避设为“否”，本场景即以此状态开始。自己检查一下吧！

- 我确实建议你关闭“温彻斯特时返航”条令，也不要在战斗区域中部就命令部队返航，而应先引导它们回程的大部分路程。否则它们可能会卡在无法进入的空域中。

当然，你可以随意行事（例如，如果你不想，并不一定要用上所有可用兵力）。祝你玩得开心，并请在 Matrixgames Command 论坛 告诉我你的想法，你可以在那里以 Tomcat84 的名字找到我。

请注意，这不是一个简单容易的场景。仅凭设置几个 AI 生成的打击任务，很可能不会成功。如果你想真正取得成功，本场景需要深思熟虑的规划以及大量的微操管理。因此，不建议新手或喜欢轻松散步的人游玩。
