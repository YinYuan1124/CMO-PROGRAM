日期/时间： 15th October, 1975 / 06:00:00 Zulu
地点：冰岛 / 北大西洋（Iceland / North Atlantic）
时长：3 天

 

引言
 
过去几周，欧洲各条战线都爆发了激烈战斗。北约驻德部队正在富尔达缺口地区进行迟滞作战，阻止了苏军装甲部队和机械化部队的前进，但人员和装备损失惨重。
 
大规模海上交战，包括美英航母编队的参战，已导致 HMS Ark Royal 号和美国航母的损失。另一方面，苏联红旗北方舰队在挪威海和北角地区已几乎被歼灭。双方都已接近其预备力量的极限。

近几个月来，被苏联占领的冰岛一直遭到北约部队的持续攻击。即便在这些攻击之后，机场仍可运作，但在起降 Su-24 Fencer 或 MiG-23 Flogger 以上的较大机型方面受到限制。第61“Kirkinesskaya”红旗海军陆战旅的残部已在雷克雅未克以及凯夫拉维克附近的雷恰内斯拜尔一带掘壕据守。
 
冰岛仍然是北约的一根刺。Oriskany 号航母战斗群、Clemenceau 号航母战斗群和 Iowa 号两栖戒备群已受命夺回冰岛。目前所有部队均已在冰岛以西就位，准备实施空海联合突击，收复该岛。

无论谁胜谁负，西部多岩的海岸注定会被染成血红……

注意：本场景包含按照 1966 年提出的一项改装方案配置为“重型突击两栖战列舰”的 USS Iowa 号。
