日期/时间： 14 August, 1975 / 22:00:00 Zulu
地点：明奇海峡 / 北大西洋（The Minches / North Atlantic）
时长：2 天 


引言
 
敌对行动在 7 天前爆发后，英国弹道导弹潜艇（SSBN）HMS Revenge 号刚刚完成快速周转，正驶出法斯莱恩海军基地，准备重返海上。
 
该艇满载 Polaris A-3 潜射弹道导弹，现已受命恢复其在英国水域附近、但仍处于指定目标射程内的核威慑巡逻。
 
情报显示，其前往巡逻海域的航渡可能已经暴露，因为大量 COMINT 截获信息提到苏联柴电潜艇和核潜艇出现在英国西部海岸附近；毫无疑问，它们正试图在 Revenge 号驶入外海之前将其逼入死角并击沉。

英国独立战略核力量必须不惜一切代价加以保护。为此，所有其他资产，无论硬件还是人员，均可牺牲。
