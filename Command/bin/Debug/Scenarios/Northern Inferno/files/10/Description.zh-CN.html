日期/时间： 26 September, 1975 / 05:00:00 Zulu
地点：科拉半岛（Kola Peninsula）
时长：6 小时


引言
 
尽管有预警，苏联对英国本土皇家空军基地动用核武器还是令人震惊。首相经与国防参谋部磋商，已同意下令对科拉半岛实施报复性打击。
 
使用 Polaris 潜射弹道导弹或 Vulcan B.2 轰炸机实施核打击的方案已被排除，因为动用它们可能使局势升级为全面核战争，而这些宝贵资产必须留作最终的谈判筹码。
 
苏格兰的大多数皇家空军基地已在苏联 SSGN 发射核巡航导弹的第二波打击中被摧毁，而英国中部具备核打击能力的皇家空军 Buccaneer 攻击机缺乏执行打击所需的航程，近期的损失已严重限制了加油机支援。 
 
这意味着必须由舰队航空兵承担这一任务。驻 HMS Ark Royal 号的第 809 中队 Buccaneer S.2D 已奉命对科拉半岛实施核打击。

Ark Royal 号编队如今进入苏联后院，去传递女王的复仇。
