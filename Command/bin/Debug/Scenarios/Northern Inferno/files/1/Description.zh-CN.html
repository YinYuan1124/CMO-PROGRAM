日期/时间：07 August, 1975 / 21:30:00 Zulu
地点： 挪威海（Norwegian Sea）
可玩方：北约（NATO）
时长： 3 天


在直布罗陀海峡跟踪一艘苏联 Echo II 级潜艇时，护卫舰 HMS Ashanti 号被击沉，人员伤亡惨重。在伦敦，首相将此次事件的责任完全归咎于苏联，并要求苏联总理道歉并作出适当赔偿。

与此同时，苏联政治局指责皇家海军危险地违反国际海洋法，并将该事件称为“悲剧性的，但不可避免”。双方均已让其海军部队进入全面戒备状态。

苏联的战斗机、攻击机和轰炸机增援部队已大量抵达科拉半岛，使原本就强大的驻军规模进一步扩大。其中最新、最令人生畏的力量是苏联战略空军的两支 Backfire 团，共拥有六十架轰炸机。Backfire 将负责支援北方舰队向挪威海的推进，为北方舰队海军航空兵现有的三个 Badger 团增添令人生畏的打击力量。

在挪威海，北约的 STANAVFORLANT（常备大西洋海军部队）已从法斯莱恩出航，在扬马延岛附近进入战时状态，并采取反潜部署。

在收到直布罗陀事件的消息后不久，北约所有部队均已进入二级战备状态，现正为战争做准备。

战争真的不可避免吗？


游戏提示：
北约的水下监视网络（SOSUS）会很快向你提供大量水下接触目标，使地图显得杂乱。不要惊慌！并非所有目标都是敌方潜艇。给 SOSUS 操作员一点时间，让他们开始识别中立目标、生物目标等。这些接触目标的颜色会变成绿色。你可以利用这段时间开始安排空中巡逻、向部队下达命令等。一旦开始出现对“绿色”目标的确定分类，就右键单击每个所需接触目标并选择“过滤掉”，将其滤除。这样会从地图上移除该接触目标几乎所有的视觉信息，只保留其图标，从而让你专注于调查和攻击可能的敌方潜艇。
