Command 不是“第一人称射击游戏”，但它提供了战术层面的精细度，可以执行非常聚焦的任务。本教程就是一个例子。你只有一艘舰艇和一架直升机，独自行动，但由你指挥。

本想定假设一艘美国军舰在锡德拉湾执行典型的低强度“武力展示”任务。利比亚长期声称整个锡德拉湾都是其领海，而根据《联合国海洋法公约》（UNCLOS），通常的领海界限是 12 海里。美国故意让舰艇驶过世界其他地区认为是国际水域的区域，以此传递信号。目标不是开火，而是提醒利比亚美国的实力。

当然，事情不会顺利。你为什么要问这种问题？

对于想轻松阅读的人，以及因为设计想定时有时会用到，可在此查阅 UNCLOS 全文：http://www.un.org/depts/los/convention_agreements/texts/unclos/closindx.htm

本想定也用于向玩家介绍 Command 的其他方面。

对想定设计者来说，Command 提供了大量选项。其中之一是能够通过添加或移除传感器或武器来修改想定中的现有平台，也可以修改平台的其他方面。例如，这里我假设在想定开始前不久，Yorktown 号因爆炸受损。火已扑灭，但许多部件被毁，已无法使用。你可以点击屏幕右侧信息面板中的“损管”按钮查看详情，也可以点击“传感器”和“武器”按钮查看报告的部分内容。此外，可用武器数量也已减少——你可以调整单位挂载和弹舱中的具体武器数量。最后，舰体总损伤为 10%。Yorktown 号仍是一台可怕的战争机器，但可以说今天它状态不佳。

设计者还可以添加航行禁区。进入后，它们会在战术地图上以高亮区域显示。本想定假设利比亚的实际领海是美国舰机和飞机的禁入区。

给想自己编写想定的人一点建议：由于 Command 选项繁多，我建议从像本教程这样小而简单的想定开始，随着经验积累再逐步提高复杂度。
