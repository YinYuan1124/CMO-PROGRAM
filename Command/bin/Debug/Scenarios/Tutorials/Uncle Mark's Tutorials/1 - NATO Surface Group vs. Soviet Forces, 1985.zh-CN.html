欢迎！我叫 Mark Gellis。我并未正式受雇于 Matrix Games 或 Warfare Sims，但我喜欢 Command，也喜欢为它编写想定。这是我持续努力的一部分，旨在帮助刚接触 Command 的玩家学习这款游戏，从而获得最大乐趣。

本教程是一个非常基础的冷战战斗。设定为 1985 年第三次世界大战爆发，你指挥一支小型水面行动群（SAG）。你的任务是搜索苏联舰艇和潜艇，并在它们进入大西洋、威胁北约船队之前将其摧毁。

你的兵力包括三艘军舰——一艘英国驱逐舰、一艘荷兰护卫舰和一艘德国护卫舰。你还有三架直升机，用于在舰艇前方侦察海域和搜索潜艇。

和往常一样，我在本教程的 .zip 文件中包含了一个 .ini 文件，可用于将该想定更新到未来的数据库版本。现在你不需要对它做任何操作；它是为将来需要时准备的。

享受本教程吧！
