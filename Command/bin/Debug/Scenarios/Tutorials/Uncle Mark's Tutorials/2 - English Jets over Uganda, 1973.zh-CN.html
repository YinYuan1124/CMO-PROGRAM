这是我持续编写的 Command 系列教程中的第二篇，至少部分目的是为新玩家提供教学。

这是一个“纯空战”想定——没有舰艇或潜艇，只有飞机和地面单位。

局势相当简单。1972 年，伊迪·阿明与英国断绝外交关系，并将几家在乌干达运营的英国公司国有化。本想定假设在此之后，一系列事件导致乌干达与英国之间的敌对行动升级。英国决定有必要进行一次武力展示。

肯尼亚向英国提供了其一个空军基地的使用权。

你指挥一支由皇家空军多个中队分遣队组成的打击部队。你有三个基本任务：首先在空中重创乌干达空军并夺取制空权；其次在恩德培上空执行侦察任务；最后对选定的地面目标实施空袭。
