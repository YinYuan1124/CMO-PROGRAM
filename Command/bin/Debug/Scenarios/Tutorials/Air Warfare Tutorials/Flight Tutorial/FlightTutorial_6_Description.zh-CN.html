欢迎来到现代空中拦截教程。

这是系列教程中的第六篇，旨在教授玩家《Command》空中作战的基础知识。本教程将涵盖以下内容：

  • 击落装备短程尾后导弹的飞机。
  • 击落装备中程和远程导弹的飞机。

本教程进行期间会弹出重要消息。你可以在随教程附带的 documents 文件夹中找到这些消息的 PDF 文件。默认位置为：C:\Program Files (x86)\Command Modern Operations\Scenarios\Tutorials\Air Warfare Tutorials\Flight Tutorial\Documents。

Steam 用户的位置为：C:\Program Files (x86)\Steam\steamapps\common\Command - Modern Operations\Scenarios\Tutorials\Air Warfare Tutorials\Flight Tutorial。
