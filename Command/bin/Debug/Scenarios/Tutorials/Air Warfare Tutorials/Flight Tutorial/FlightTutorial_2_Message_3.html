Now that your F-16Is are airborne, you need to create a Support Mission for your AEW (Airborne Radar) and ECM (Airborne Jammers) aircraft.

First, you need to de-select the Reference Points used by the AAW Patrol. Go to the "Mission + Ref. Points" menu and select the option "De-Select All Reference Points".

Now you need to place two Reference Points for the Support Mission. Go back to the "Mission + Ref. Points" menu and select "Add Reference Point". You can also use "CTRL + right mouse button" and select "Add Reference Point".

Place them on the map and then key "Ctrl + F11" to create the new mission.

This time select "Support" from the third menu and press "OK", then assign your two Nahshon and two Hermes 900 to the mission.
