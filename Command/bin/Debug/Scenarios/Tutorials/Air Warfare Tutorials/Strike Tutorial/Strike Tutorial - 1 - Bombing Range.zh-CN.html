本教程旨在帮助新玩家理解空对地轰炸的方法与细节。在当今空军中，轰炸并不像空对空（A2A）任务那样光彩夺目，但当那些“光环飞行员”从闪亮的白色战马上下来，并意识到世界不再围着“白骑士拯救落难少女”转时，他们就会承认：把弹药投送到地面目标才是他们存在的意义。空对地瞄准通常分为两类：近距离空中支援（CAS），涉及地面部队；以及打击，即独立于地面部队发现并摧毁目标。每种类型下还有若干子类，但本教程将专注于简单的打击任务，每次只使用一架飞机。

大多数现代战斗机被称为“多用途”，意味着它们既能执行空对空任务以争夺制空权，也能执行空对地任务打击地面目标。有些飞机，如 F-15C 或 MiG-31，是纯粹的空对空；另一些如 A-10 或 Su-25 则是纯粹的空对地，这些“飞行坦克”主要专注于与部队近距离接触时的 CAS。

今天我们将使用 F-16，它是当今使用最广泛、最通用的现代飞机之一。你可以认真研究各种 F-16 型号，但这对本教程并不重要。所选型号能够使用多种弹药，以演示所需的游戏功能。如果你想了解更多，可以随时查阅资料。

别担心，在后续教程中我们会使用俄制、欧洲和中国制造的其他飞机，让你也能熟悉它们。

进入游戏四处看看。你在马里有一个空军基地，还有一些为你整齐排好的目标。本教程没有针对你的防御，所以你可以自由练习而不会被射击。享受学习这款出色游戏的过程。
