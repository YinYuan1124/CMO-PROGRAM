# 奖励剧本 架空时间线 #

日期/时间：1973年10月24日 / 07:30:00 祖鲁时间
地点：地中海东部
可玩阵营：第五分舰队
持续时间：8小时

自20世纪60年代中期起，苏联海军日益向海外部署。1964年，地中海分舰队（又称“第五分舰队”）成为苏联第一支前沿部署的海军力量。

到1966年，苏联已将其地中海兵力扩充至平均15艘舰艇，从埃及到直布罗陀进行港口访问。苏联在地中海东部的这一部署，最初旨在对抗美国在那里部署的战略巡航导弹潜艇和弹道导弹潜艇。随着美国导弹射程和精度的提高，苏联人必然被拖入远洋作战，以搜寻并消灭搭载这些导弹的潜艇。

苏联在地中海首次以显著方式展示海上力量是在1967年阿以冲突期间。1967年6月的六日战争中，苏联增派兵力，以示对阿拉伯国家的支持。那是苏联首次抓住机会，展示其愿意动用海军力量影响该地区重大事件的意愿。在那场危机中，苏联地中海分舰队的规模达到约70个单位，其中一些驻扎在塞得港和亚历山大，以防止以色列袭击这些港口。

苏联的这一存在迅速扩大。到1970年，该分舰队在地中海东部稳定保持70艘舰艇，后勤支援来自黑海，另有部队定期从北方舰队和波罗的海舰队“交叉配属”。在赎罪日战争（1973年10月）期间，兵力从52艘增至95艘（包括十余艘驱逐舰和近两打潜艇），数量超过美国第六舰队。

这一次，苏联准备投入大量资产和资源，以协助其阿拉伯盟友的目标。但他们究竟愿意走多远？
