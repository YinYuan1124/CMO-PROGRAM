# 奖励剧本 架空时间线 #

日期/时间：1967年6月8日 / 11:00:00 祖鲁时间
地点：埃及 - 西奈半岛
可玩阵营：美国第六舰队
持续时间：1天

对“自由”号（USS Liberty）的袭击至今仍是美以关系中的痛处之一。

在以色列与若干阿拉伯国家之间的六日战争期间，美国官方保持中立。战争开始前几天，“自由”号（呼号“Rockstar”）——一艘电子情报船（官方称“技术研究船”）——奉命前往地中海东部，在西奈北海岸附近的国际水域执行信号情报收集任务。战争爆发后，由于担心其驶近巡逻区域时的安全，多份电文被发往“自由”号，要求将其与埃及和以色列海岸的允许最近接近点（CPA）分别从12.5海里和6.5海里增加到20海里和15海里，后来又改为对两国均为100海里。然而，由于电文处理和传递效率低下，这些CPA变更电文收到得太晚。

1967年6月8日下午，“自由”号遭到以色列空军和海军攻击，严重受损；最终34名船员死亡，174人受伤。

“自由”号遭袭时，两个美国海军航母特混大队（“萨拉托加”号，Saratoga，“美利坚”号，America）正在克里特岛以南的地中海东部。这艘情报船呼叫立即援助，以抵御持续的攻击。

这就是接下来可能发生的情况。
