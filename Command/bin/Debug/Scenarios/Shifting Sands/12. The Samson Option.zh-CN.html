# 奖励剧本 架空时间线 #

日期/时间：1973年10月10日 / 11:00:00 祖鲁时间
地点：埃及 - 西奈半岛
可玩阵营：以色列
持续时间：4小时

官方上，以色列不是核国家。

赎罪日战争最初几天，阿拉伯联军在北部和南部边境取得出其不意的突破，以色列军方几乎陷入恐慌。惊慌的国防部长摩西·达扬（Moshe Dayan）对以色列总理果尔达·梅厄（Golda Meir）说：“这是第三圣殿的终结。”他是在警告以色列即将全面战败，但“圣殿”也是核武器的代号。

达扬在内阁会议上再次提出核问题，警告国家正接近“最后手段”的临界点。当晚，梅厄批准组装十三枚核“物理包”，用于装备斯多特米哈（Sdot Micha）空军基地（又称“第二联队”）的“杰里科”I（Jericho I）导弹，以及特尔诺夫（Tel Nof）空军基地（又称“黑色中队”）的F-4E战机，以打击叙利亚和埃及目标。这些核武器将在绝对必要时使用，以阻止前线全面崩溃，或作为以色列遭毁灭后的最终报复。不过，这些准备工作是刻意以容易被观察到的方式进行的，很可能是向美国和苏联发出信号。

美国国务卿亨利·基辛格（Henry Kissinger）于10月9日上午得知核警报。当天，为了履行其阻止以色列对集结中的阿拉伯军队发动先发制人打击的承诺与警告，美国总统尼克松下令启动“镍草”行动（Operation Nickel Grass）——一次大规模空运，以补充以色列的全部物资损失（尤其是飞机），并提供额外的支援装备，例如全新的电子干扰机，用于对抗阿拉伯的防空导弹。（据轶闻，基辛格曾对萨达特说，美国空运的原因是，以色列人已非常接近“动用核武器”。）

在这个假想剧本中，美国迟迟未能承诺提供关键援助，以色列领导层最终绝望到迈入核深渊。
