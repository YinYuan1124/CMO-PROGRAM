日期/时间： 1982年5月1日 / 15:30:00 祖鲁时间
地点：福克兰群岛 - 南大西洋
持续时间：1天
可玩阵营：英国

[假想想定]

4月27日，阿根廷舰队从基地出航，驶向英国海军最后报告的位置。阿根廷海军的大部分兵力，包括其航空母舰“五月二十五日”号（ARA Veinticinco de Mayo），此时都已出海。其任务是：搜寻并交战英国特混舰队，或将其彻底摧毁，或给予足够重创，迫使其撤出战区。

阿根廷的总体计划是对英国舰队实施三路“钳形”攻击：以“贝尔格拉诺将军”号（General Belgrano）编队为“南路部队”（代号第79.3特混大队），以西北方向的航母编队（第79.1特混大队）和更北面的“飞鱼”导弹护卫舰编队（第79.4特混大队）为另外两路。

钳形攻势的北面两路最接近皇家海军舰艇的估计位置（而且它们也由最现代化的兵力编成：一艘满载可用攻击机的航母，加上数艘导弹战舰），因此很可能率先发起攻击；“贝尔格拉诺”号以火炮为主的第79.3特混大队随后将从南面逼近，待英国部队被削弱和打散后加入战斗。此次攻击还将得到空军岸基兵力的支援。

4月30日，情报显示英国航母编队位于福克兰群岛东北方。英国舰队自进入战区以来，已宣布在群岛周边设立200海里全面禁区（实际上是一条“禁止进入，否则开火，不予警告”的界线）。为避免给英国提供先发制人的政治借口，阿根廷三个特混大队都停留在全面禁区边缘，等待皇家海军航母编队亮出底牌。

他们没等多久：5月1日，福克兰群岛上的阿根廷占领机场遭到多方向攻击，先是“火神”轰炸机，随后是皇家海军特混大队的“海鹞”。

英国舰队在机场空袭中完成了自己的任务，但也因此暴露了大致的方位。阿根廷本土的空军攻击机已做好出击准备，“五月二十五日”号则将其搭载的 A-4Q 攻击机联队准备好，准备对英国编队实施“阿尔法打击”（以“竞技神”号和“无敌”号为优先目标），并派出 S-2 巡逻机，在攻击前对皇家海军编队进行最后定位。二战后的第一场航母对决即将开始。

 

 

历史结局（剧透）

这是一个假想想定，而它实际上曾差一点成为现实。

第一次 S-2 出动未能发现英国编队，攻击因此推迟。随后的侦察出动确实定位了皇家海军舰艇，但偏偏赶上了一个想必令人抓狂的巧合：逆风不足，无法让满载的 A-4 攻击机起飞（对不熟悉南大西洋天气规律的人来说：“风不大”就跟“埃及下雪”一样稀罕）。 尽管攻击的岸基部分本可以独立进行，但为了以一只集中起来的拳头打击英国部队，还是决定再次推迟攻击。

5月2日，当“五月二十五日”号正在放飞又一次攻击前侦察时，“贝尔格拉诺”号的南路编队遭到突袭——钳形计划随之瓦解。
