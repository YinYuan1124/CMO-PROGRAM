引言

1990年8月2日，全世界惊愕地注视着伊拉克最精锐的装甲师在两天之内入侵并占领科威特。

伊拉克领导人、总统萨达姆·侯赛因刚刚做出了一场战略豪赌：超级大国及其盟友正忙于柏林墙倒塌和德国统一之后的剧变，无暇他顾，不会投入足够的注意力和资源来阻止他吞并科威特、控制世界石油产量中相当大一部分的计划。事后看来，可以公允地说他判断错了。美国总统布什迅速组建了一个庞大的国际联盟，首先是为了保护沙特阿拉伯及周边国家免遭伊拉克进一步侵略（“沙漠盾牌”行动），随后则是将伊拉克军队逐出科威特——如有可能便和平解决，必要时则使用武力。后一选项（“沙漠风暴”行动）最终被证明是必要的。

沙漠风暴在许多方面都是第一场真正的高技术战争。它是第一场被全世界数以百万计的人每周7天、每天24小时实时观看的冲突。它是空中力量首次独自决定性地击败地面部队。它得以实现，靠的是规模超过二战诺曼底登陆的后勤集结。一个国家的整个指挥、控制与通信体系在冲突一开始就被骤然有效摧毁，这是史上首次；卫星被直接用于支援作战行动，这是首次；隐身、防区外和精确制导武器被大规模使用，也是首次。对于研究军事技术与军事艺术的人而言，这实际上是21世纪的第一场战争。

这场冲突还产生了深远的战略和地缘政治后果。当时的历史学家所预言的“历史的终结”并未发生；相反，全球各方评估了新的现实，并相应调整了各自的长期战略剧本。长期确立、又被这场战争打破的地区战略平衡，为新角色和蛰伏势力自我伸张打开了大门。基地组织与9·11袭击、对伊拉克和阿富汗的入侵以及随后旷日持久的反叛乱作战、达伊沙（Daesh），乃至俄罗斯和中国在全球舞台上的重新崛起，其根源都可追溯到沙漠风暴及其后果。

这套战役旨在重现这场冲突中的一些著名事件与行动。随着时间流逝，远离了媒体无休止的聚光灯和无尽的猜测，历史学家得以梳理出真正重要的事情以及不那么重要的事情：冲突中一时的轰动事件，如“寻找温尼巴戈”或海夫吉之战，如今被认为在战争的整体时间线上远没有那么关键。当时几乎无人注意（如果有的话）的事件，例如对伊拉克化学报复部队的时敏打击，如今则可以其重要性得到认识。其他行动，例如首夜对巴格达及其他地方的打击，或布比延海战，在当时就被正确地视为关键转折点，并且至今依然如此。

有几点需要说明。这既不是对整个冲突的“完整”呈现，也不是对其作战行动的详尽清单。在汇编一套历史想定时，精心挑选关键事件是必要的。战争的一些关键事件已被有意搁置；例如“爱国者”对射向以色列领土的“飞毛腿”袭击的拦截（以及拦截失败）——这是一个引人入胜、充满戏剧性的故事，但在 Command 想定中却是糟糕的游戏体验（没有有意义的选择可做）。阿尔费尔多斯地堡打击之类的悲剧也是如此——那是远超 Command 中常见战术挑战的情报失误。一些重要交战，如著名的“73东线”之战，或像臭名昭著的 SAS 巡逻队这样的小规模部队行动，也已被省略，因为 Command 仍不适合详细的陆战（不过未来我们重新审视这项工作时，这种情况很可能会改变）。后期的想定通常呈现出比历史上更强的伊拉克抵抗；这同样是出于可玩性的考虑。最后，这套合集主要涉及冲突中美军的行动（尽管其他国家的部队也被纳入适当的值得注意的行动中）。尽管组建的联盟由众多国家的武装力量构成，但无论好坏，美国武装力量都承担了整场冲突中绝大多数作战行动，这套合集清楚地反映了这一点。

我们还收录了若干假想想定（我们战役作品的老玩家对此已很熟悉）。我们认为，历史不仅仅是发生过的事，还包括在适当情况下（在现实的合理约束内）本可能轻易发生的事。历史有一种有趣的习性：当你以为它会向右转时，它却向左转；它会提出一些听起来荒诞不经的事件和情境——只要它们尚未发生。“伊斯兰恐怖分子在美国本土同时劫持4架客机，并用它们攻击世贸中心、五角大楼和国会大厦”在9·11之前的任何时候，都会是一部低俗小说或直接发行录像带的电影的情节。连同基于历史的想定，我们希望你能更好地理解这场决定命运的冲突中的一些关键时刻——这些时刻在战场内外塑造了21世纪的战争方式。

“在战争中，只有一个真相：人会死去。”——约翰·M·斯特拉钦斯基（John M. Straczynski），《巴比伦5号》

 

《Command: Desert Storm》是由 Wayne Stiles 制作的战役合集。战役与想定引言由 James John Simakas 与 Dimitris V. Dranidis 撰写。
